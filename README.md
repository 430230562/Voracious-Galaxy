# Voracious-Galaxy
Hello and Welcome to the Voracious Galaxy. The goal of this project is to overhaul Stellaris and make it much more Vorny. While still in the early stages this mod will grow and adapt as time goes on.

**HOW TO INSTALL**
1) Unzip the provided files into Documents/Paradox Interactive/Steallris/Mod
2) Make sure that the "voracious_galaxy" folder and "voracious_galaxy.mod" file are in the mod folder and are NOT in a folder inside the mod folder
3) Launch and Enjoy!

**Known Mod  Compatibility**
This mod _SHOULD_ work with any mod on the most up to date Stellaris builds as well as ALL DLCs. However if YOU encounter an incompatibility while playing please reach out to a member of the team on the official discord server.
Tested Mods that Work:
-Gigastructural Engineering
-Lustful Void and it's Addons
-Vanilla Framework (Lover's Lab)
